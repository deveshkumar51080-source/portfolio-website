R.A.D.A.R-X (Robotic Adaptive Detection and Response System)

Robotics Embedded Systems Sensor Fusion Hardware Integration C++ Problem Solving

Project Overview

R.A.D.A.R-X is an intelligent, gesture-driven robotic platform powered by an ESP32 microcontroller. It merges multi-modal sensor fusion with deterministic safety overrides, allowing contactless hand-gesture navigation while autonomously preventing collisions and identifying stationary human presence in real time.

Core Purpose & Key Functionality

Contactless Gesture Navigation
Decodes hand motions (directional swipes) using the APDS9960 sensor via I2C to dictate real-time motor maneuvers.
Multi-Modal Spatial Awareness
Fuses 24GHz mmWave radar (HLK-LD2410), laser Time-of-Flight LiDAR (VL53L0X), ultrasonic ranging (HC-SR04), and infrared proximity to eliminate sensor blind spots and detect still human micro-movements.
Autonomous Safety Override
Implements a three-tier risk management architecture (Safe / Warning / Danger). If any sensor registers an obstruction inside the critical threshold (<15 cm), firmware instantly overrides user input, disconnects motor power via a relay kill-switch, and triggers audiovisual alarms.
Adaptive Actuation
Regulates dual DC motors through an L298N H-Bridge using pulse-width modulation (PWM) for speed calibration and tight turning radiuses.

Technical Skills & Competencies Demonstrated

Firmware & Embedded Systems
Embedded C++, Arduino framework, multi-sensor polling loops, deterministic state machines, and fail-safe logic design.
Hardware Protocols & Interfacing
I2C bus management with shared addressing, multi-baud UART hardware serial communication, and PWM driver integration.
Sensor Fusion & Signal Conditioning
Integrating acoustic, optical, infrared, and radio frequency (RF) sensors into a unified proximity decision matrix.
Power Electronics & Circuit Design
Dual-rail DC power distribution using LM2596 buck converters, resistive voltage dividing for 5V-to-3.3V logic protection, inductive load isolation, and common-ground topologies.
Robotics & Control Systems
Closed-loop obstacle mitigation, H-Bridge motor driving, and physical relay emergency-stop integration.
